# Personal Budget Tracker

## About the Project

This is a simple Personal Budget and Expense Tracker built using HTML and CSS.

The project allows users to enter expense information and view sample expenses in a table.

## Features

- Add expense form
- Date input
- Expense name input
- Amount input
- Expense category dropdown
- Expense table
- YouTube video
- Budget Tracker help section
- Hover effects on the table
- Responsive page structure

## Technologies Used

- HTML
- CSS
